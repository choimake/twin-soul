# レビュー出力テンプレート（ユースケース記述）

レビュー結果は次の骨格を起点に組み立てる。

```md
## レビュー概要

- **ステータス**: 合格 / 不合格
- **重大指摘**: N件
- **提案指摘**: N件

## 指摘

### 重大

- **ルール**: 代替と例外が事後条件で区別されているか（`references/rules/must-distinguish-alternative-exception.md`）
- **問題**: ゴール未達で終了する経路が代替フローに置かれている
- **修正**: 事後条件（成功時）に到達しない経路を例外フロー（E 番号）へ移す

### 提案

- **ルール**: 暗黙の前提が明示されているか（`references/rules/should-explicit-assumptions.md`）
- **問題**: フローがストーリーに無い前提に依存しているが、前提として書かれていない
- **修正**: 暗黙の前提に A 番号で追加し、本文から（A1）の形で参照する

## 次の手順

[重大指摘がある場合]

- 上記を修正してから、再度レビューを実施してください

[指摘が無い場合]

- レビュー合格です。ユーザー承認を求めます
```

指摘は `重大`、`提案`、`任意` の順で並べる。

指摘が無い場合は、次の形を使う。

```md
## レビュー概要

- **ステータス**: 合格
- **重大指摘**: 0件
- **提案指摘**: 0件

## 指摘

指摘はありません。ユースケース記述は品質基準を満たしています。

## 次の手順

- ユーザー承認を求めます
```
