## UC-01: 〈ユースケース名（動詞句のゴール名）〉

| 項目 | 内容 |
| --- | --- |
| ユースケース名 | 〈動詞句のゴール名〉 |
| 対応ストーリー | 〈ストーリーID〉 |
| 主アクター | 〈ゴールを開始するアクター〉 |
| 副アクター | 〈あれば。無ければ「なし」〉 |
| 事前条件 | 〈開始前に真と保証される条件。フロー中で再検査しない〉 |
| 事後条件（成功時） | 〈正常完了時に真である状態〉 |
| 事後条件（失敗時） | 〈失敗・異常終了でも守られる状態（最低保証）〉 |
| トリガー | 〈開始の契機。事前条件と区別する〉 |

### 基本フロー

1. 〈アクター〉は、〈操作〉する。
2. システムは、〈処理・応答〉する。
3. 〈以降、ゴール達成までの最頻経路を番号付きで書く。目安は 3〜9 ステップ〉

### 代替フロー

- **〈N〉a. 〈分岐条件〉の場合**
  - 〈N〉a-1. 〈手順〉
  - 〈N〉a-2. 〈復帰先を明示する。例: 基本フロー 4 に戻る／成功として終了する〉

### 例外フロー

- **E1. 〈例外条件〉**
  - 発生ステップ: 基本フロー 〈N〉（原因が生じた瞬間ではなく、検出されるステップを書く）
  - システムは、〈エラー応答等〉を返す。ユースケースを〈終了する／基本フロー 〈N〉 に戻る〉。
