# README

## 目的

「読んだ人が次の行動を取れるか」だけを問う。完全性より最初の一歩の明確さを優先する。

## 使う場面

- `README.md` 新規作成時
- 既存 README のレビュー・全面改稿時
- README が肥大化し残す内容の整理が必要なとき
- はじめ方・導線・関連文書リンクの見直し時

## 手順

1. 対象 README を特定。一意でなければ `@path` を確認。
2. レビュー・新規作成・全面改稿のいずれかを判定。曖昧なら既存 README あり→レビューを優先。
3. README 自体を読み、判断に必要な最小限の関連文書だけ読む。
4. README に残す内容と別文書へ逃がす内容を分ける。
5. 新規作成・全面改稿では [assets/readme-template.md](assets/readme-template.md) の `概要 / なぜ必要か / はじめ方 / サポート` を起点に組み立てる。
6. `review`→入口文書としての問題点と改善案を返す。作成・改稿→テンプレートを埋めた本文案を返す。

詳細判断とレビュー観点は [references/readme-knowledge.md](references/readme-knowledge.md) を参照。

## 期待する出力

- 最初の一歩が分かる構成案・本文案・または指摘
- README に残す内容と別文書へ逃がす内容の区別
- テンプレート骨格に沿った新規作成・全面改稿・またはレビュー
