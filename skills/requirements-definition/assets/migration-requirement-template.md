# 移行要求用テンプレ（コピー用）

要求定義ルールの第 5.3 節に相当する。第 5.2 の汎用テンプレに、次の行を加える。

移行では、期間と終了条件を必ず残す。受入基準に「いつまでに」「切替完了の定義」を含めてもよい。

```markdown
### （移行の主題）

- 記述
- 根拠
- 有効期間 / 廃止条件（必須に近い扱い）
  いつからいつまで／どのマイルストーン以降はこの節の対象外にするか
- 受入基準
- 優先度
- 担当 / オーナー

- 出典
- 上位要求からの紐づき
- 検証方法のメモ
```

汎用の枠は [requirement-item-template.md](requirement-item-template.md) を併せて参照する。
