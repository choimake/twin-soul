# 1 件分の汎用テンプレ（コピー用）

要求定義ルールの第 5.2 節に相当する。第 4 節（と 4.6 層早見）に照らし、層に不要な行は削る（曖昧な空欄行を残さない）。コピー用テンプレの項目名にはコロンを付けない。本文は項目の直下に字下げで段落や下位箇条書きを続けてよい。

## 見出し付き（第 3 レベル見出し）

```markdown
### （短い見出し名 何の要求か一言）

- 記述
- 根拠
- 受入基準
- 優先度
- 担当 / オーナー

- 出典（原則。争点・規程由来は事実上必須）
- 上位要求からの紐づき（ソリューション層で必須に近い）
  満たすビジネス要求／ステークホルダー要求の見出し名または要約
- 検証方法のメモ
```

ビジネス層・ステークホルダー層では「上位要求からの紐づき」は省略しがちでよい。ソリューション層（機能・非機能）では、第 4.5 節のとおりこの項を必須に近い扱いで埋める。

## 箇条書みの深さだけ置く場合（### を置かない）

第 3 レベル見出し `###` を置かない場合は、箇条書きの塊の先頭に短いタイトル一行を置き、下位項目を字下げする。

```markdown
- （短い見出し名）
  - 記述
  - 根拠
  - 受入基準
  - 優先度
  - 担当 / オーナー
  - 出典
  - 上位要求からの紐づき
  - 検証方法のメモ
```
