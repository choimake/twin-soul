# レビュー出力テンプレート

レビュー結果は次の骨格を起点に組み立てる。

```md
## レビュー概要

- **ステータス**: 合格 / 不合格
- **重大指摘**: N件
- **提案指摘**: N件

## 指摘

### 重大

- **ルール**: 手書きルールを保持しているか（`references/rules/preserve-handwritten-rules.md`）
- **問題**: 既存の project 固有ルール `/secrets/local/` が削除されている
- **修正**: 既存ルールを維持し、追加項目だけ差分で足す

### 提案

- **ルール**: 生成物・キャッシュと整合しているか（`references/rules/match-repo-artifacts.md`）
- **問題**: `.next/` の ignore 漏れがある
- **修正**: Next.js 生成物用の ignore 項目を追加する

## 次の手順

[重大指摘がある場合]

- 上記の指摘を修正してから、再度レビューを実施してください

[指摘が無い場合]

- レビュー合格です。ユーザー承認を求めます
```

指摘は `重大`、`提案`、`任意` の順で並べる。

指摘が無い場合は、次の形を使う。

```md
## レビュー概要

- **ステータス**: 合格
- **重大指摘**: 0件
- **提案指摘**: 0件

## 指摘

指摘はありません。`.gitignore` は品質基準を満たしています。

## 次の手順

- ユーザー承認を求めます
```
