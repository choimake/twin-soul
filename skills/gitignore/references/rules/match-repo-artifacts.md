# 生成物・キャッシュと整合しているか

## ねらい

ビルド生成物、キャッシュ、仮想環境、IDE ファイルの ignore 漏れは、不要なファイルが commit される原因になる。逆に、実際に使う生成物を誤って ignore すると開発が止まる。

## チェック観点

- `dist/`、`.next/`、`.venv/`、`.terraform/` など、リポジトリで実際に生成される成果物が ignore されているか
- ビルド生成物、キャッシュ、仮想環境、IDE ファイルの ignore 漏れがないか
- リポジトリのビルド設定（`package.json` scripts、`pyproject.toml`、`Cargo.toml` など）と ignore 項目が整合しているか

## 指摘する基準

- 明らかな生成物・キャッシュの ignore 漏れがある場合は **提案** として指摘する
- 追跡すべき生成物を誤って ignore している場合は **重大** として指摘する

## 例

### 悪い例

```gitignore
# Next.js プロジェクトなのに .next/ が含まれていない
node_modules/
```

### 良い例

```gitignore
# Next.js + Python 混在リポジトリ
.next/
.venv/
dist/
```

## 補足

- リポジトリの手掛かりから生成物を推定し、不足があれば追加を提案する
- 判別しにくい項目は削除せず、理由付きで保留にする
