# レビュー出力テンプレート

レビュー結果は次の骨格を起点に組み立てる。

```md
## レビュー概要

- **ステータス**: 合格 / 不合格
- **重大指摘**: N件
- **提案指摘**: N件

## 指摘

### 重大

- **ルール**: 受け入れ条件が明確に定義されているか（`references/rules/must-have-acceptance-criteria.md`）
- **問題**: 受け入れ条件セクションが無い、または曖昧すぎる
- **修正**: 検証可能な条件をチェックボックス形式で追加する

### 提案

- **ルール**: ベストプラクティスを参照しているか（`references/rules/must-reference-best-practices.md`）
- **問題**: ベストプラクティスセクションが無い
- **修正**: Web検索でタスク関連のベストプラクティスを取得し、ベストプラクティスセクションに追加する

## 次の手順

[重大指摘がある場合]

- 上記の指摘を修正してから、再度レビューを実施してください

[指摘が無い場合]

- レビュー合格です。ユーザー承認を求めます
```

指摘は `重大`、`提案`、`任意` の順で並べる。

指摘が無い場合は、次の形を使う。

```md
## レビュー概要

- **ステータス**: 合格
- **重大指摘**: 0件
- **提案指摘**: 0件

## 指摘

指摘はありません。plan fileは品質基準を満たしています。

## 次の手順

- ユーザー承認を求めます
```
