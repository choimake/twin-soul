# 合議調査 統合レポート

統合報告は次の骨格を起点に組み立てる。指摘列挙型では「指摘一覧」を、判定投票型では「判定投票」を使う。

```md
## 合議調査レポート

### 実行条件

- **調査対象**: [対象とスコープ]
- **対象 skill**: [SKILL.md のパス / なし]
- **エージェント数**: N = [数]
- **モデル**: [調査サブエージェントごとのモデル識別子。実行環境の既定なら「既定」]

### 指摘一覧（確度順）

| 確度 | 出現数 | 位置 | 分類 | 重要度 | 指摘の主旨 | 根拠 |
| ---- | ------ | ---- | ---- | ------ | ---------- | ---- |
| 高 | 3/3 | [ファイル:行] | [分類] | [高/中/低] | [主旨] | [引用または理由] |
| 中 | 2/3 | [ファイル:行] | [分類] | [高/中/低] | [主旨] | [引用または理由] |
| 低 | 1/3 | [ファイル:行] | [分類] | [高/中/低] | [主旨] | [引用または理由] |

### 判定投票（判定投票型の場合のみ）

| 項目 | 判定の分布 | 確度 | 備考 |
| ---- | ---------- | ---- | ---- |
| [項目] | 可 3 | 高 | |
| [項目] | 可 2 / 条件付き可 1 | 中 | 少数意見: [要旨] |
| [項目] | 可 1 / 条件付き可 1 / 不可 1 | 低 | 要確認: [割れた理由の要約] |

### 注意

- 確度は N 体の独立調査での再現性であり、正しさの保証ではない。同一モデルの誤りは相関するため、高確度でも採用前に根拠を確認する
- 低確度（単独）の指摘にも価値ある洞察が含まれ得るため、除外していない
```

組み立て時の注意:

- 単独指摘を省略しない
- 同一指摘の主旨・根拠は、最も具体的な記述を代表として使う
- 並び順は確度 → 重要度とする
- 「注意」節は省略しない
