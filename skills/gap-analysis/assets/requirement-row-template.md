# 1 要件分テンプレ（ID なし既定）

1 要件だけを切り出して書く場合に使う。文書全体を組み立てるときは [gap-analysis-template.md](gap-analysis-template.md) を起点にする。

連番 ID が無い場合は、見出しを短いラベルのみにする。

## 〈要件の短いラベル〉

| 項目           | 内容 |
| -------------- | ---- |
| PRD要件        |      |
| 実現可否       |      |
| 根拠・実証内容 |      |
| 制限事項       |      |
| 代替案・回避策 |      |
| PRD仕様変更案  |      |

---

（参考）入力に要件 ID がある場合だけ、見出しを `### T-01: 〈ラベル〉` のようにしてよい。
