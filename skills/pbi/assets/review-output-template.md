# レビュー出力テンプレート（PBI）

レビュー結果は次の骨格を起点に組み立てる。

```md
## レビュー概要

- **ステータス**: 合格 / 不合格
- **重大指摘**: N件
- **提案指摘**: N件

## 指摘

### 重大

- **ルール**: 受入基準が明確か（`references/rules/must-have-acceptance-criteria.md`）
- **問題**: 受入基準セクションが無い、または検証不能
- **修正**: 検証可能な条件をチェックボックス形式で追加する

### 提案

- **ルール**: 確認方法が具体か（`references/rules/must-have-verification-or-agreement.md`）
- **問題**: 確認方法が無い、または「確認する」のみ
- **修正**: 確認者・確認対象・受入判断の見える化を短く追記する

## 次の手順

[重大指摘がある場合]

- 上記を修正してから、再度レビューを実施してください

[指摘が無い場合]

- レビュー合格です。ユーザー承認を求めます
```

指摘は `重大`、`提案`、`任意` の順で並べる。

指摘が無い場合は、次の形を使う。

```md
## レビュー概要

- **ステータス**: 合格
- **重大指摘**: 0件
- **提案指摘**: 0件

## 指摘

指摘はありません。PBI は品質基準を満たしています。

## 次の手順

- ユーザー承認を求めます
```
