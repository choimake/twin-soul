# 〈PBI タイトル〉

## ユーザーストーリー（任意）

> **As a** 〈ロール〉
>
> **I want to** 〈やりたいこと〉
>
> **So that** 〈価値・目的〉

必要なときだけ使う。無理に As / I want / So that へ分解しない。

## 背景・目的

〈なぜこの PBI があるか。達成したいこと、前提、必要ならスコープ外〉

## 受入基準

〈完了の定義。検証可能な項目を簡潔なチェックリストにする〉

- [ ] 〈検証可能な条件1〉
- [ ] 〈検証可能な条件2〉

## 確認方法

〈誰が・何を見て受入判断するか。受入基準で自明なら1行でよい〉

- 〈確認者・確認対象・記録先など〉

## メモ・論点

〈未決事項、制約、依存、スコープ外、必要なら短い作業メモ〉

- 〈論点またはメモ〉

## 参考リンク・仕様ドキュメント（必要時のみ）

- [〈タイトル〉](〈URL〉)

---

フロントマター不要の場合は先頭の `---` ブロックを削除する。

通常は「背景・目的」「受入基準」「確認方法」「メモ・論点」を既定にする。タスクブレイクダウンや詳細な実装手順は、必要な場合だけ別の plan file へ分ける。
