# レビュー出力テンプレート

レビュー結果は次の骨格を起点に組み立てる。

```md
- `path/to/file`
  - **ルール**: コードとコメントの内容を一致させる（`references/rules/keep-comments-in-sync.md`）
  - **優先度**: 重大
  - **問題**: コメントが現在の実装と矛盾している
  - **修正**: コメントを更新するか、コメントが不要なら削除する
```

指摘は `重大`、`提案`、`任意` の順で並べる。

追加スコープが必要な場合は、指摘の後に次を添える。

```md
追加で確認したいファイル:

- `path/to/related-file`: 参照元との整合を確認したいため
```

判断材料が不足する場合は、不確実性を明示する。

```md
前提:

- `path/to/file` 以外は未確認のため、外部参照がある場合は結論が変わる可能性がある
```

指摘が無い場合は、次の形を使う。

```md
指摘はありません。

残るリスク:

- `path/to/file` のみ確認したため、関連設定やテストまでは未確認
```
