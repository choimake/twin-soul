# GCP Security Baseline

## 目的

小規模チーム・個人が Google Cloud の環境を構築・見直す際に、最低限のセキュリティ対策と予算アラートを確認する。設定は自動適用しない。

## 使う場面

- プロジェクト・組織の新規作成や初期設定の見直し
- Terraform の google provider を使ったコードの確認
- 予算アラート、IAM、SA キー、監査ログなどの確認漏れの点検

## 手順

1. 対象のプロジェクト・課金アカウント、組織（Organization）の有無、Terraform コードの有無を確かめる。
2. 確認を始める前に [references/checklist.md](references/checklist.md) を読む。
3. コードがあれば各項目のリソース・属性を探す。組織がない構成では、組織ポリシーの代わりに `auto_create_network`、`google_project_default_service_accounts`、バケット属性など、チェックリストにあるリソース側の設定で判定する。代替がない組織専用項目は対象外とする。
4. 手作業の項目、コードだけでは判定できない項目はユーザーに確認する。コード上の設定だけで実環境への反映を断定せず、情報が足りなければ「要確認」とする。
5. 全項目を「済 / 未 / 対象外 / 要確認」で判定し、根拠とともに表で返す。推測で「済」にしない。

## 期待する出力

対象と組織の有無、確認範囲（コード／ユーザーの回答）を添え、次の表を返す。任意項目も任意と分かるように残す。

| 項目 | 判定 | 根拠（ファイル:行 またはユーザーの回答） |
| --- | --- | --- |
| チェックリストの項目名 | 済 / 未 / 対象外 / 要確認 | 確認した設定・回答、または不足している情報 |

## 検証

- 全項目に判定があり、「済」には確認範囲に応じた根拠、「対象外」には理由がある。
- 未確認の Terraform 対応や実環境の状態を推測で断定していない。
- 組織の有無とリソース側の代替を区別し、任意項目を必須扱いしていない。
- 設定変更・自動適用は実行していない。
