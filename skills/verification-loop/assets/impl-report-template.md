# 実装報告

実装サブエージェントは次の骨格で、ラウンドディレクトリの `impl-report.md` に書く。会話への返答は完了の一行だけにする。

```md
## 実装報告

- **状態**: 完了 / 着手前に停止（指示の食い違い）

### 変更ファイル

| ファイル | 要旨 |
| -------- | ---- |
| path/to/file | [何をどう変えたか] |

### 指示との食い違い（あれば）

- [指示のどこが、実物のどこと食い違ったか。`path:行` と引用]

### 指示外の変更（あれば）

- [どこを、なぜ変えたか。変える前に取った実測]

### 足したテストの効き目（コード変更のとき）

| テスト | 戻した実装 | 結果 |
| ------ | ---------- | ---- |
| [テスト名] | [どの分岐・行を戻したか] | 落ちた / 落ちなかった |

### 修正指示・指摘への反論（あれば）

- [どの指示に、どの一次情報で反論するか]
```

注意:

- 落ちなかったテストは何も守っていない。その事実を書き、書き直す
- 「通った」という申告だけでは合格の根拠にならない。コマンドの結果は実行検証が記録する
