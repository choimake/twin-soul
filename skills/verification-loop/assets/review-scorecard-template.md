# レビュー スコアカード

レビュー結果は次の骨格を起点に組み立てる。基準は委譲時に渡された合格基準を列挙し、それぞれ採点する。

```md
## スコアカード

### 基準ごとの採点

| 基準 | スコア (0.0–1.0) | 根拠（該当箇所の引用） |
| ---- | ---------------- | ---------------------- |
| [基準1] | 0.0 | [ファイル:行または抜粋] |
| [基準2] | 0.0 | [ファイル:行または抜粋] |

### 総合

- **総合スコア**: 0.00（既定は基準スコアの単純平均。加重が必要な場合は委譲時に明示された集計方法を使う）
- **品質ゲート**: [draft / review / production]（合格ライン: 0.00）
- **判定**: 合格 / 不合格

### 修正指示（不合格の場合のみ）

命令形で書く。「〜が悪い」ではなく「〜を〜に変更せよ」。対象ファイルと変更内容を特定する。

1. [対象ファイル]: [具体的な変更内容]
2. [対象ファイル]: [具体的な変更内容]

### 根拠を引用できない箇所（あれば）

- [どの基準について、何が確認できなかったか]
```

採点時の注意:

- 「全体として良いか？」でまとめない
- 根拠を引用できない場合は、その旨を明示し、該当基準のスコアを低くする
- 任意の改善提案はスコアカードの合否判定とは分け、「任意提案」として末尾に短く列挙してよい
