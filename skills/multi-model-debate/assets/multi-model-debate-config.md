# multi-model-debate の設定

`multi-model-debate` skill は、議論を始めるときにこのファイルを読む。起動時の指定があれば、そちらを優先する。席が書かれていなければ、skill はその場で席を聞く。

## 席

議論役の席を 2〜3 個、1 行に 1 席で `- <CLI> / <モデル>` の形で書く。

- CLI は、議論役を呼ぶツール（claude / codex / agy / cursor-agent など）
- モデルは、そのツールが受け付ける識別子をそのまま書く
- 同じ組を 2 席に置かない

例: `- claude / opus`

## ラウンド数の上限

ラウンド 1（独立案）を含む回数を数字で書く。全席が「変更なし」になれば、上限の前に止まる。書かなければ 2 回。
